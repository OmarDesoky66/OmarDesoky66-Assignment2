# Calculator

A simple console-based calculator built with **C#**. It performs basic arithmetic operations and validates user input.

## Features

* Addition, subtraction, multiplication, and division.
* Input validation for numbers and operations.
* Division-by-zero handling.
* Repeat calculations without restarting the application.

## Technologies

* C#
* .NET Console Application

## How to Run

1. Clone the repository.
2. Open the project in Visual Studio or VS Code.
3. Run the application.

## Usage

1. Enter the first number.
2. Enter the second number.
3. Choose an operation (`+`, `-`, `*`, `/`).
4. View the result.
5. Press any key to continue or `n` to exit.
